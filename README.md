# # 🤖 Robotic — Interactive 3D Website

A modern, immersive **interactive 3D robotic website** designed with a clean dark interface and an engaging 3D experience.

🌐 **Live Website:** https://roboticstructure.netlify.app/  
📦 **GitHub Repository:** https://github.com/Ahmadraza970/robotic

## ✨ Features

- 🤖 Interactive 3D robotic experience
- 🌑 Modern dark-themed UI
- 🎨 Clean and minimal design
- ⚡ Smooth interactive experience
- 📱 Responsive layout
- 🧩 3D elements powered by Spline
- 🚀 Fast and lightweight frontend

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- Spline 3D
- Netlify

## 🌐 Live Demo

Check out the live project:

**https://roboticstructure.netlify.app/**

## 🚀 Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/Ahmadraza970/robotic.git
```

### 2. Open the project

```bash
cd robotic
```

### 3. Run the website

Open `index.html` in your browser, or use **Live Server** in VS Code.
